# Governance

qrab-qapi is a subproject of [qrab](https://github.com/qrab-dev/qrab) and is
governed by the qrab project. It has no separate governance: qrab's
[GOVERNANCE.md](https://github.com/qrab-dev/qrab/blob/main/GOVERNANCE.md)
applies here as written, including its principles, roles, lazy-consensus
decision making, the path to becoming a reviewer or maintainer, and how the
governance itself changes.

In this repository:

- the maintainers and reviewers of these crates are listed in
  [MAINTAINERS.md](MAINTAINERS.md), and the code owners who approve pull
  requests in [.github/CODEOWNERS](.github/CODEOWNERS);
- the contribution rules, including the DCO sign-off and the pull request
  flow, are in [CONTRIBUTING.md](CONTRIBUTING.md);
- security reports follow [SECURITY.md](SECURITY.md), and Code of Conduct
  reports [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Larger changes to these crates, such as new public APIs or changes to the
generated representation, start as an issue in this repository under the
same rules qrab applies to larger changes.
