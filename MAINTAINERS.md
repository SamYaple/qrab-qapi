# Maintainers

qrab-qapi is a subproject of [qrab](https://github.com/qrab-dev/qrab). Its
maintainers are qrab maintainers, under the roles described in qrab's
[GOVERNANCE.md](https://github.com/qrab-dev/qrab/blob/main/GOVERNANCE.md).
qrab's [MAINTAINERS.md](https://github.com/qrab-dev/qrab/blob/main/MAINTAINERS.md)
lists the maintainers of the whole project.

| Name | GitHub | Affiliation | Areas |
| --- | --- | --- | --- |
| Sam Yaple | [@SamYaple](https://github.com/SamYaple) | Independent | All crates |

Maintainers review and merge pull requests, triage issues, cut releases and
handle security and Code of Conduct reports. They are the code owners in
[.github/CODEOWNERS](.github/CODEOWNERS).

## Contacting the maintainers

- Questions, bugs and feature requests: open an
  [issue](https://github.com/qrab-dev/qrab-qapi/issues).
- Changes: open a pull request; see [CONTRIBUTING.md](CONTRIBUTING.md).
- Security issues: do not open a public issue. Follow
  [SECURITY.md](SECURITY.md).
- Code of Conduct reports: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Automation

Coding agents that work on the qrab project act through the
`qrab-dev-agent[bot]` GitHub App. The App is not a maintainer and cannot
approve its own pull requests; a human maintainer reviews everything it
opens.
